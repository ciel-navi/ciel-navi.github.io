アプリ開発部

アプリ開発部では、生活や業務の中にある小さな迷いを減らすアプリを企画・開発しています。記録、検索、判断、習慣化など、毎日使う行動を軽くすることを重視しています。

Planning

企画・要件整理

作りたい機能をそのまま並べるのではなく、誰が、どの場面で、何を楽にしたいのかを整理します。

Interface

UI / 体験設計

触ったときの分かりやすさ、画面サイズへの適応、アニメーションや導線まで含めて設計します。

Build

Android / Web開発

APK配布、LP連携、Webアプリ、管理画面など、公開して使える状態まで実装します。

相談できること

  • アプリの新規企画、MVP制作、プロトタイプ制作
  • Android APKの配布ページ、更新導線、インストール説明
  • 既存アプリのUI改善、画面設計、機能追加
  • Google Play公開前のテスト版、LP、告知導線の整備
